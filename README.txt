Arduino Traffic Light System

A small Arduino project which stimulates a traffic light system, using various components.

About
The project controls a traffic light using an Arduino and includes:
-Red and Yellow and Green LEDs
-SG90 Servo Motor
-IR sensor
-Buzzer

The system works in a continuous loop as a real traffic does cycling through the three traffic colors in controlled time limit, and includes a Crossing Gate made with servo motor, and if the IR sensor detects movement while the Crossing gate is in the way, the buzzer starts beeping.

this is one of my early projects which was important for my understanding towards embedded systems and how its software interacts with the hardware components.
